# Калькулятор окон для Telegram Web App

Простой веб-калькулятор окон и бот на Telegraf, который принимает данные из веб-приложения и отправляет PDF-смету через pdfmake.

## Требования
- Node.js 18+
- npm
- Токен Telegram-бота от BotFather
- HTTPS-доступный URL для `index.html` (ngrok или собственный хостинг)

## Установка
1. Склонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <repo-url>
   cd test-mcp
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```

## Настройка
1. Откройте `bot.js` и укажите свои значения:
   - `BOT_TOKEN` — токен бота от BotFather.
   - `WEB_APP_URL` — HTTPS-ссылка на опубликованный `index.html` (например, выдаёт ngrok).
2. (Необязательно) отредактируйте цены в `index.html` в объекте `PRICES` под свои тарифы.

## Запуск
1. **Быстрый локальный просмотр (без Telegram, демо-кнопка):**
   ```bash
   python -m http.server 5500
   ```
   Откройте [http://localhost:5500](http://localhost:5500). Появится кнопка «СФОРМИРОВАТЬ PDF (демо)» — она не отправляет данные боту, но показывает, что будет передано (в консоли и всплывающим окном).

2. **Полноценный запуск с ботом:**
   - Поднимите локальный сервер так же, как в пункте выше (или через VS Code Live Server).
   - Пробросьте HTTPS через ngrok (или другой туннель) для порта вашего сервера:
     ```bash
     ngrok http 5500
     ```
     Скопируйте выданный `https://...` и подставьте в `WEB_APP_URL` в `bot.js`.
   - Запустите бота:
     ```bash
     npm run start
     ```
   - Откройте бота в Telegram, отправьте `/start`, нажмите кнопку «Открыть калькулятор», заполните данные и нажмите «СФОРМИРОВАТЬ PDF». Бот отправит файл-смету.

## Полезно знать
- При изменении размеров, створок или опций цена пересчитывается мгновенно на клиенте.
- PDF генерируется на сервере бота и отправляется как документ.
- Для остановки бота нажмите `Ctrl+C` в терминале.
